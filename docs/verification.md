## 網站與共用核心

- 首頁在桌面 1440 px 與手機 390 px 寬度檢查九張真實頁面預覽、斜放拼貼、名稱、播放入口及水平溢出。預覽固定步驟，沒有執行中的動畫，也不寫入播放進度或啟動休息倒數。
- 從首頁進入回到封面，重設步驟與休息狀態；播放中重新整理恢復目前步驟。同一簡報的兩個分頁可獨立操作，不同簡報使用各自的進度。
- 模擬簡報模組載入延遲，確認 `?start=1` 保留至播放器初始化完成，之後才清除。損壞或不可使用的 `sessionStorage` 不妨礙播放。
- 直接開啟放映路徑、返回首頁、舊 `/presenter` 導回首頁與未知路徑的返回入口均通過。
- 測試簡報採用紫色配色、Georgia 字型、4:3 舞台與自訂位移轉場。確認共用控制不依賴 Workshop 的頁碼、教材資料或樣式，兩份簡報的 CSS 不影響首頁或彼此。

## 重跑

在根目錄執行：

```sh
npm ci
npm run typecheck
npm test
npm run test:examples
npm run build
npx playwright install chromium
npm run build:test
npm run test:browser
```

瀏覽器驗證使用 `.preview-dist/` 與 5274 端口；開發網站使用 5173。Playwright 每次執行會重建 `test-results/`，其中的截圖與轉場量測只代表最近一次測試批次，可透過對應測試重新產生。

正式建置不登錄測試簡報。本次沒有發布至遠端；靜態主機的 SPA 路由回退設定見根目錄 [README](../README.md#靜態部署)。
