# 現行網站架構（2026-10-08）

Backend Workshop 是根目錄 Slides 網站的一份簡報，播放路徑為 `/slides/backend-workshop`。首頁使用九張實際頁面的靜態斜放拼貼。共用導覽與舞台位於根目錄 `src/presentation/`，本模組 `src/definition.tsx` 保留專屬版型、動畫及章節指引；僅保留休息倒數。以下保留 Workshop 的視覺設計記錄，新增簡報以 [作者指南](../../docs/authoring.md) 為準。

# 淺色視覺

參考 Apple iPhone Duo 頁面的留白、主體比例與字級對比。網站中的課程介面與圖解為本專案元件，沒有引用 Apple 圖片或遠端字型。

## 固定頁面框架

在 1600×900 設計舞台上，所有一般教學頁與程式頁使用同一組座標：左右留白 96 px、章節標籤頂端 52 px、標題頂端 86 px，標題統一 48 px／60 px 行高。頁尾高度 22 px、距底端 32 px。不再為程式頁覆寫標題字級或位置。

頁碼使用等寬數字與固定的三欄空間，個位數、兩位數、三位數都保持相同對齊。開場問題也沿用標題基線；封面、休息、問答保留專用構圖。

內容區從 y=184 開始。所有程式碼頁移除「閱讀重點／觀察結果」文字區與保留空間，編輯器垂直置中。Schema 欄位對照圖保留，所有步驟的編輯器位置固定。14 行頁面仍使用 27 px 字級、34 px 行高。

curl 五條指令共用一個 14 行編輯器，以五個手動步驟聚焦，沒有模擬請求與結果。Swagger 以操作說明加並列兩個 JSON 編輯器呈現，預期結果在各編輯器上方，一開始顯示。

聚焦範圍明確對應來源行，相關註解與折行共同選取。框的位置由實際 DOM 行量測；首次掛載與提詞預覽直接定位，只有頁內步驟切換滑動。文字明暗與行號共用同一選取範圍，最後一步也不將全部程式恢復高亮。

## 講義目錄與課程總覽

一般投影片保留原有縮放比例 min((視窗寬 − 232)/1600, 視窗高/900)，但舞台與控制列改為螢幕中央，左右等量留白。封面、休息、問答仍為全幅。指引是獨立覆蓋層，不參與尺寸計算；寬度至多 180 px，依舞台實際左緣與 96 px 內容留白計算，距教材保留 24 px。視窗寬度小於 900 px 時隱藏章節指引並使用完整視窗寬度，手機操作列保留主要控制。

投影指引採連續的小節列表，主章節使用 11 px 提示。焦點行置於視窗中央，文字 16–18 px，字下方加 2 px、24% 藍色的短底線；其他行縮放為 72%，依距離淡化。每個項目固定 80 px 高，最多約 400 px 的可視區域，上下邊緣透明漸隱；沒有框線、選取底色、展開箭頭或底部講義連結。換小節時列表位移與文字縮放以 0.5 秒 ease-out 交接；同小節不重播，快速操作立即轉向最新目標。滾輪或鍵盤可單獨瀏覽，下一次導航恢復跟隨；減少動態效果直接切換。

沿用 Notion 原始名稱、順序與穩定 ID；非連續小節仍正確定位。沒有直接內容的 Syllabus、Backend & Web Overview、RESTful API Design、Introduction to FastAPI 只作為章節提示，不重複成為進度項目。開場問題與流程圖歸入第一個 Learning Goals；Relational Model 與 Schema 各自聚焦。投影的瀏覽位置僅為本地元件狀態，不保存或同步。

總覽保留固定頁首，內容頂端中央放 180 min；十三個主題以左七右六呈現，先左欄再右欄。序號 16 px、主題 29 px、每列 52 px；主題文字置中，沒有各段時間。

## 構圖

- 封面：白底，單行 Backend Workshop 為 156 px／600 字重、字距 -3 px，視覺中心上移 22 px。NYCU SDC 以 18 px 深灰置於底部中央，距底端 124 px；SDC 使用 700 字重。兩組文字固定，操作列顯示時保持間距。右上方超出舞台的橢圓弧面使用白至淺灰 #e3e5e8 的霧面漸層與固定柔和陰影；背景獨立裁切，不攔截操作。24 秒循環僅動畫 transform：12 秒內由水平 -24 px／旋轉 -1° 移至 +24 px／+1°，再平順返回；左下保留留白。僅投影片畫面播放，首頁預覽、離場快照與減少動態效果保持起點的靜態弧面；返回封面時重新開始循環。
- 開場：Client、Server、Database 固定位置，五個手動狀態逐步展示請求與資料保存。
- 概念與圖解：學習目標改為三欄大字；Python 概念與環境確認使用開放留白；Route 對照使用文字與細線。比較和資料分組才使用面板。
- HTTP：各部分組成連續的訊息閱讀面，標籤與引線靠近對應內容；目前區段保留淺藍焦點。
- 程式：共用固定標題、深灰編輯器、來源行號與大型聚焦框。14 行上限與來源分段不變。
- 資料模型：放大欄位矩陣與模型欄寬；相同行名在 Create、Update、Response 之間直接對照。
- Table、Schema、ERD、JOIN：白底、細分隔線，欄位名稱與關係線可直接對照。
- 操作介面由根目錄的共用播放器提供；Workshop 專屬色彩、字型與頁面幾何限定於 `data-deck="backend-workshop"`。

## 動畫

一般揭露使用 10 px 位移或透明度，約 0.45–0.5 秒。參數帶入、篩選重排、資料提交與還原保留實際教學動作。開場的請求標記為 0.65 秒。每一步完成即停止，沒有鏡頭移動、脈衝光圈或無教學用途的縮放。

跨頁仍為 0.3 秒淡化：不透明的新頁在下方，舊頁在上方淡出。舞台容器持續存在。快速操作取代過期動畫，首頁預覽靜態，減少動態效果時直接切換。

教材版本為 8、90 頁與 180 分鐘。curl 合併保留 ID 30001，Schema 移到 CRUD 與 JOIN 之後、Connection 之前；刪除回顧頁的來源流程整合至 ID 44。HTTP、Path／Query、Route／Endpoint 與 REST 仍由 ConceptScenes.tsx 呈現。升版保留穩定 ID 與計時，步驟回到起點，已移除頁面導回對應保留頁。
